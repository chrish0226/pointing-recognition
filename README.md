# 指差确认：肩肘腕几何版

当前规则为 `arm_geometry_v8`，模型沿用 RTMW3D-L / YOLOX-s TensorRT FP16。前、左、右以人体朝向为基准，每人累计三向各一次后红框变绿，通过后继续累计；R 重置，Q/Esc 退出。

## 本次改变

本轮直接修改现有检测程序，复用原模型和 TensorRT 引擎：

- 小幅前指增加时序几何补充：同一只手已确认侧指后，结合前臂投影收缩、腕位向内及上抬变化判断，补充深度偏平时漏掉的前指。左侧或右侧动作之后均可触发，不要求完整左→右→前。
- 这类弱深度前指至少连续支持 0.12 秒，并检查完整二维腕位速度；跨胸移动途中不提前加前。确认后允许小幅端点抖动，减少前指被重复记成左指。
- 明确侧向伸臂可保持在较低位置，不再仅因低于上一指的高度就拒绝；下降运动仍需通过稳定检查。辅助朝向不能轻易清除明确横指。
- 参考轴已重新稳定且出现明确抬手时，可以提前结束弱动作等待。保留普通摆臂、腰部双手操作、放手下降抑制，以及单臂无效点隔离。
- 逐帧手臂日志增加几何、朝向融合、时序、最终过滤四阶段方向及拒绝原因，便于定位漏判发生在哪一步。


动作证据仅使用肩、肘、腕，代码在 `balanced_pointing_rules.py` 和 `arm_geometry.py`：

- 融合肩→腕、肘→腕在人体坐标系中的空间方向与二维投影，修正屈肘横指被短投影优先规则误记为前指的问题。
- 侧指转前指优先使用三维前伸证据；深度偏平时，仅在受限的躯干视角及连续手臂收缩、上抬证据下补充，不把任意胸前屈肘姿态都算前指。
- 前指优先使用最近支持帧；快速但稳定的空间换向至少三帧/0.06 秒，常规动作至少四票/0.08 秒，弱深度补充至少连续 0.12 秒，高帧率增加票数。上抬途中、放手下降和双手同时操作增加抑制。
- 参考轴转身抑制同时核对投影变化，避免仅深度抖动就长时间禁止低位动作。鼻耳朝向辅助不能独自把屈肘横指改成前指。
- 实时入口仅向规则传入身体 17 点，不传入手指；逐帧日志也不再保存手指。肩髋用于建立人体参考，脚部仅辅助行走抑制，鼻耳可选且不作为通过条件。

模型引擎、三维解码、无人工 ROI、每人独立累计以及红绿框规则沿用基线。运行规则不读取视频编号、预期次数、人工时段或固定左→右→前顺序。

## 验证

110 项自动测试通过，包括真实动作顺序及确认时段、整理手套/普通摆手不计数、侧身前指、弱深度小幅前指、快速跨胸过渡、端点抖动，以及手指缺失/随机/NaN 时结果一致和实时输入边界检查。回归数据来自参与调参的素材，不是独立现场准确率测试。

完整视频重新推理及剩余错误见 [当前验证记录](verification/arm_geometry_v8/verification.json)。结果视频和逐帧日志保存在本机 `outputs/arm_geometry_v8`；未上传工厂视频。主规则和几何模块分别记录 SHA256，并生成整套规则指纹。

21:14:58 新视频由左/右/前 23/12/0 次提升到 24/22/19 次，29 组中 16 组确认完整三向，仍漏左 5 次、右 7 次、前 10 次；9 段旧视频所有轨迹的累计次数与 v7 一致。16 与 13 的右指、3 的部分方向及 22:32 视频末组左右仍有漏判/误判，不能视为全部修复。模型仍输出原来的 133 点，排除手指不会减少模型主干的推理计算量。
