# 肩肘腕规则 v6 实测记录

RTMW3D-L / YOLOX-s TensorRT FP16 引擎未改动。实时入口只将身体 17 点交给规则，动作证据仅用肩、肘、腕；肩髋用于人体坐标，鼻耳仅可选辅助朝向。没有手指输入、人工 ROI、固定动作顺序或按预期次数补齐。

88 项自动测试通过；9 段视频完整重新运行检测、跟踪、姿态和规则，共 4277 帧。逐帧次数、红绿状态、参考轴及 H.264 完整解码均通过程序检查。数据已用于调参，不代表独立现场准确率。

|---|---|---|
| 8 | 1 / 1 / 1 | 左→右→前正确；确认 2.77、3.13、3.80 秒 |

22:32 长视频不能仅看总次数：约 28.5 秒左指和 43.2 秒右指在本版漏掉，属于相较 v5 的回退；48.1 秒左指误记右，50.5 秒右指漏掉，21.31 秒额外右计数仍在。右累计 7 次也不意味着七次右指均正确。

16 的实际右指与前指，在模型预测的肩肘腕空间向量中很接近。本版恢复较明确的前伸，拒绝边界模糊的换向，不使用手指或按顺序猜出右指。后续需要更多角度的标注样本来改进人体朝向和动作分段，当前不能认为所有自然动作已解决。

本机结果视频位于 `outputs/arm_geometry_v6/<视频名>/result.mp4`，同目录有逐帧日志和单视频验证记录。模型推理 FPS 与包含绘制/日志/录像的整条处理速度不同；本轮后者约 23–44 FPS，未实测物理摄像头、RTSP 或 Jetson。

代码分支 `improve/arm-geometry-v6`，上一版和 v4 基线可从 Git 历史恢复。详细结果、引擎哈希和规则指纹见同目录 verification.json；工厂视频及引擎不上传代码仓库。
